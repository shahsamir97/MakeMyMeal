Main is the latest branch. Please checkout Main before testing the app.

The app Make Meal uses Gemini API to create recipes based on the photo provided by user. You can either provide a photo of a food item for which you want to create the recipe or you can take a photo of food ingredients you have and Gemini will generate some recipes you can make with these ingredients.
